# Synthetic Sample Laboratory Reports

This repository does not include a ready-to-upload public laboratory report PDF
for the demo.

Do not test with real patient health information. Use a synthetic report with
obviously fake data, such as:

```text
SYNTHETIC DEMO DATA - NOT A REAL MEDICAL RECORD

Patient Name: Demo Patient
Patient ID: DEMO-001
Gender: Female
Date of Birth: 1990-01-01

Report: Complete Blood Count
Sample Collection Time: 2026-07-07 10:00

Test                 Result   Unit     Reference Range
Hemoglobin           13.4     g/dL     12.0 - 15.0
White Blood Cells    6500     /uL      4000 - 11000
Platelets            250000   /uL      150000 - 450000

SYNTHETIC DEMO DATA - NOT A REAL MEDICAL RECORD
```

You can paste synthetic content into a document editor, export it as PDF, and
upload it through the demo UI. This only demonstrates the document processing
pipeline. It does not clinically validate extraction accuracy.
